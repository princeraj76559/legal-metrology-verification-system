# Legal Metrology Verification System

Shared starter for the team's two-day MVP.

## Start the frontend

1. Install Node.js 20 or newer.
2. In `frontend`, run `npm install`.
3. Run `npm run dev`.

## Team ownership

- `src/pages/admin` — Member 1
- `src/pages/applicant` — Member 2
- `src/pages/officer` — Member 3
- `backend` — Member 4
- `src/components`, `src/layouts`, `src/styles` — shared; coordinate before editing.

Read `docs/API-CONTRACT.md` before writing any API call.
