# Team rules

1. Work only in your assigned branch and folder.
2. Do not change roles, statuses, API paths, or response shapes without team agreement.
3. Reuse the components in `frontend/src/components` and variables in `frontend/src/styles/theme.css`.
4. Before merging, run the frontend locally and check your role route.
5. Keep API requests in `frontend/src/services/api.js`; do not call `fetch` directly from a page.

## Branches

- `main` — stable integrated work only
- `feature/admin-dashboard` — Member 1
- `feature/applicant-portal` — Member 2
- `feature/officer-portal` — Member 3
- `feature/backend-api` — Member 4
